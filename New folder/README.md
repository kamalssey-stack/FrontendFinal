# 📚 Pustok — Книжный интернет-магазин (Frontend Project)

Учебный веб-проект многостраничного интернет-магазина по продаже книг. Проект разработан на чистом стеке технологий без использования тяжелых фреймворков и готов для демонстрации.

---

## 🛠 Используемые технологии
* **HTML5** — семантическая разметка страниц.
* **CSS3** — стилизация, Flexbox, Grid-сетки, адаптивный дизайн для мобильных устройств и планшетов.
* **JavaScript (ES6+)** — динамический рендеринг контента, управление корзиной, фильтрация, интерактивность.
* **Bootstrap & FontAwesome** — готовые компоненты интерфейса и векторные иконки.

---

## 📖 Назначение страниц и файлов

### 1. Страницы (HTML)
* **`index.html`** — главная страница сайта. Содержит верхнее меню (header), промо-слайдер, подборки популярных книг, новинок и подвал (footer).
* **`shop.html`** — полный каталог книг с возможностью выбора категорий (Романы, Классика, Драма, Поэзия, Детские книги и др.).
* **`product.html`** — подробная карточка отдельной книги: большая обложка, рейтинг, отзывы, аннотация и кнопка добавления в корзину.
* **`wishlist.html`** — персональный список «Отложенное» (Wishlist), куда сохраняются понравившиеся книги.
* **`checkout.html`** — страница подтверждения и оформления заказа: ввод адреса, имени покупателя, подсчёт итоговой стоимости.
* **`login.html`** — форма для авторизации и регистрации покупателя в системе.
* **`blog-gallery.html`** — детальная статья блога с интерактивной галереей и боковой панелью архивов.
* **`bootstrap-demo.html`** — тестовая страница для проверки адаптивной сетки и интерактивных компонентов Bootstrap.

### 2. Системные ресурсы (`assets/`)
* **`assets/css/style.css`** — единый файл стилей: типографика, цветовая палитра магазина, анимация переходов и адаптивность под экраны смартфонов и планшетов.
* **`assets/js/data.js`** — эмуляция серверной базы данных. Хранит массивы объектов с информацией о книгах: ID, название, автор, цена, обложка, категория, рейтинг и отзывы.
* **`assets/js/main.js`** — ядро интерактивности сайта:
  * Получает данные из `data.js` и динамически отрисовывает карточки книг в DOM-дерево.
  * Реализует добавление и удаление товаров из корзины.
  * Обеспечивает работу списка избранного (wishlist).
  * Производит пересчет итоговой стоимости покупок.
  * Управляет выпадающими меню, табами и модальными окнами.
* **`assets/image/`** — структурированное хранилище всех графических ресурсов сайта.

## 🚀 Как запустить проект
1. Открыть папку `end-frontend-main` в редакторе (VS Code).
2. Запустить файл `index.html` с помощью расширения **Live Server** (или просто открыть двойным кликом в браузере).
